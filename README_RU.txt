РАСПРОСТРАНЕНИЕ ИГРЫ
---------------------
Готовая игра распространяется одним файлом:

   AegisNoliki_Setup_1.1.0.exe

Игрок запускает установщик, устанавливает игру и получает готовое приложение.
Python, PyCharm, pygame, pip, PyInstaller, Inno Setup и исходный код игроку НЕ нужны.

Установщик автоматически создаёт:
- ярлык AegisNoliki на рабочем столе;
- пункт AegisNoliki в меню Пуск;
- запись удаления игры в Windows;
- файлы игры, музыку и фоны.

ПЕРВЫЙ ЗАПУСК
-------------
После установки и первого запуска игра показывает настройку игры под себя.
Можно выбрать никнейм, язык, тему, разрешение, оконный/полноэкранный режим и звук.

Затем появляется знакомство с основными возможностями:
- смена звуков и звуковых пакетов;
- установка собственного фона;
- кастомизация интерфейса и эффектов;
- встроенный музыкальный плеер.

Перед первым ONLINE-матчем игра отдельно объясняет правила режима:
- матч состоит из 3 раундов;
- на каждый ход даётся 7 секунд;
- перед каждым раундом случайно выбирается, кто ходит первым;
- после раунда показывается текущий счёт;
- после третьего раунда показывается итог матча.

СБОРКА ДЛЯ РАЗРАБОТЧИКА
------------------------
Этот архив содержит исходный код и инструменты сборки.

На компьютере разработчика:
1. Установите Python 3.12, 3.13 или 3.14.
2. Установите Inno Setup 6.
3. Запустите BUILD_WINDOWS.bat.
4. BAT автоматически собирает игру через PyInstaller.
5. Затем Inno Setup создаёт финальный установщик.
6. Готовый установщик появляется в папке installer.

Для игрока эти шаги НЕ выполняются.

ПРЕДУПРЕЖДЕНИЕ WINDOWS
-----------------------
Самостоятельно собранный неподписанный EXE может показать SmartScreen.
Для коммерческого распространения рекомендуется подписывать Windows-сборку
сертификатом Code Signing.
